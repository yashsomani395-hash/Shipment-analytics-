## 📐 Project Overview

This project answers five strategic business questions about shipment operations:

1. **Which region has the worst on-time delivery performance — and why?**
2. **Is freight cost related to distance? Which carriers deviate from expected pricing?**
3. **Which customers experience the most delays — and what drives it?**
4. **What data quality issues were found and how were they resolved?**
5. **What is the single best weekly KPI to predict operational issues early?**

Every answer is computed programmatically from the dataset. No values are hardcoded.

## 🚀 Quick Start

### 1. Clone & Install

```bash
git clone https://github.com/your-username/shipment-analytics.git
cd shipment-analytics

python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Generate the Dataset

```bash
python generate_data.py
```

This creates `data/shipments.csv` with ~5,000 rows and realistic data quality issues.

### 3. Run the Dashboard

```bash
streamlit run app.py
```

> **Windows note:** If `streamlit` is not on your PATH, use:
> ```bash
> python -m streamlit run app.py
> ```

Open [http://localhost:8501](http://localhost:8501) in your browser.

### 4. (Optional) Run Analysis from CLI

```bash
python analysis.py
```

This prints Q1–Q5 results to the terminal.

## ☁️ Deployment

### Streamlit Cloud (Recommended)

1. Push this repository to GitHub.
2. Go to [share.streamlit.io](https://share.streamlit.io).
3. Connect your repo → set **Main file path** to `app.py`.
4. **Before deploying**, add `data/shipments.csv` to the repo (remove it from `.gitignore`), or generate it via a startup script.

> **Tip:** You can commit `data/shipments.csv` directly since it's a small synthetic file (~500 KB).

### Render

1. Create a new **Web Service** on [render.com](https://render.com).
2. Connect your GitHub repo.
3. Set **Build Command:** `pip install -r requirements.txt && python generate_data.py`
4. Set **Start Command:** `streamlit run app.py --server.port $PORT --server.address 0.0.0.0`

### Replit

1. Import the GitHub repo to [replit.com](https://replit.com).
2. In `.replit`, set:
   ```toml
   run = "python generate_data.py && streamlit run app.py --server.port 8080"
   ```

## 🧼 Data Cleaning Summary

| Issue | Count | Action |
|-------|-------|--------|
| Duplicate rows | ~50 | Dropped |
| Duplicate IDs | ~5 | Kept first |
| Inconsistent region/carrier names | ~800 | Normalised |
| Impossible delivery dates | ~10 | Set to NaT |
| Negative freight cost | ~8 | Set to NaN |
| Zero freight cost | ~5 | Set to NaN |
| Missing numeric values | ~150 | Median imputed |
| Empty customer names | ~80 | Filled "Unknown" |

---

## 🔧 Assumptions

1. "On-time" = `actual_delivery ≤ expected_delivery`.
2. Missing numeric values are imputed with the column median (robust to skew and outliers).
3. Zero and negative freight costs are data entry errors, not genuinely free shipments.
4. Duplicate shipment IDs with differing data: the first occurrence is treated as authoritative.
5. Outliers are flagged but not removed (domain confirmation required).
